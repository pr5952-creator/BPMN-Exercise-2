Scenario 1: Hotel Room Reservation

The process starts when a guest submits a room booking request with check-in and check-out dates. The reservation system checks the availability of rooms for the requested dates.
If no rooms are available, the system notifies the guest that no rooms are available and the process ends. If rooms are available, the system requests an advance payment or deposit from the guest.
If the payment fails, the guest receives a payment failure notification and the process ends. If the payment is successful, the system confirms the booking and generates a booking reference number. The system then sends a booking confirmation email containing the reservation details to the guest. The process then ends.


Scenario 2: Loan Application Processing

The process starts when a customer submits a personal loan application. The bank's system verifies the applicant's documents and credit score.
If the documents are incomplete or invalid, the system rejects the application and notifies the customer. The process then ends.
If the documents are valid, the system checks the applicant's eligibility based on credit score and income. If the applicant is not eligible, a rejection notification is sent to the customer and the process ends.
If the applicant is eligible, the application is forwarded to the loan officer for final approval. If the loan officer approves the loan, the system disburses the loan amount and sends an approval notification to the customer. If the loan officer rejects the loan, a rejection notification is sent to the customer. The process ends after the appropriate notification is sent.

Scenario 3: Job Applicant Recruitment Process
The process starts when a candidate submits a job application online. The HR system screens the application against the minimum eligibility criteria.
If the candidate does not meet the eligibility criteria, the system sends a rejection notification and the process ends.
If the candidate meets the eligibility criteria, the HR team schedules a technical interview. The technical panel evaluates the candidate's performance. If the candidate fails the technical interview, HR sends a rejection notification and the process ends.
If the candidate passes the technical interview, the candidate is scheduled for an HR or managerial round. If the candidate is rejected in this round, a rejection notification is sent and the process ends.
If the candidate is selected, the system generates an offer letter and sends it to the candidate. The process ends after the offer letter is sent.
